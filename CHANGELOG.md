# Juke-Nuke Beta Changelog

## v1 private/public beta

Current reviewer build.

Highlights:

- Docker / TrueNAS deployment
- Music, movies, video and photos
- Karaoke workflow
- Radio and IPTV
- Playlists
- Retro / arcade features
- Shared playback state and remote interaction
- Resume behaviour for supported video playback
- TMDB metadata and artwork enrichment
- Local sidecar artwork support
- In-app beta Report button
- Persistent Docker storage
- TrueNAS quick-start compose file

The beta remains under active development. See `KNOWN-ISSUES.md` for areas still being refined.
