# Juke-Nuke Known Issues — Private Beta

This file lists issues and rough edges already known during the pre-release review period.

## Current status

Juke-Nuke is a release candidate and still has a small number of bugs and rough edges to iron out before public release.

## Known areas still being refined

- Some playback edge cases may need further tuning depending on media format and browser/device.
- UI layout and spacing are still receiving final polish across different screen sizes.
- Emulator/retro compatibility can vary depending on ROM format and required BIOS files.
- IPTV behaviour depends on the provider, stream format and credentials supplied by the user.
- Metadata/artwork quality depends partly on local sidecar files and optional TMDB enrichment.

## Reporting a new issue

The built-in **REPORT** button is the quickest route and sends feedback directly back to the developer mailbox.

Useful details include:

- Juke-Nuke version
- TrueNAS / Docker version
- Browser or device
- Steps to reproduce
- Expected result
- Actual result
- Logs/screenshots where useful

This list will be updated as the private beta progresses.
