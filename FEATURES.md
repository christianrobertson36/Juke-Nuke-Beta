# Juke-Nuke Beta Features

Juke-Nuke is a self-hosted entertainment centre aimed at touchscreen, TV, games-room and home-bar setups.

## Core areas

- Music library and playback
- Movie and video library
- Photos
- Karaoke with singer workflow
- Radio
- IPTV
- Playlists
- Retro / arcade features
- Shared playback state
- Remote / companion interaction
- Resume behaviour for supported video playback
- TMDB metadata and artwork enrichment
- Local sidecar artwork support

## Why Juke-Nuke

The goal is not simply to copy Jellyfin, Navidrome or RomM. Juke-Nuke is designed as one unified room-friendly interface where media, karaoke and retro entertainment can live together without switching between several separate apps.

Karaoke is a particular focus during the beta because the self-hosted ecosystem has relatively few polished options for a dedicated home karaoke experience.

## Platforms

Current beta focus:

- Docker
- TrueNAS SCALE
- Dockge

Additional application work is also underway for Windows and Android.

## Beta status

This is a pre-release build. Features, layout and behaviour may change as feedback comes in.
